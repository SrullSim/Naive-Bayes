Naive-Bayes:
A lightweight Python project for data classification using the Naive Bayes algorithm.

- Overview
This project demonstrates automatic classification of data using the Naive Bayes algorithm. It is designed for learning and practicing probabilistic models, and can be a starting point for further projects in data analysis and machine learning.

- Main Features
Load and read CSV data files

Build probability dictionaries from the dataset

Classify new examples using the Naive Bayes model

Clear, commented code

Easy to extend for new categories or domains

- Requirements
Python 3.7 or higher

pandas library

- How to Use
Place your CSV dataset file in the data folder.

Edit and run classify.py from the model folder, specifying the correct file path and label column.

- How It Works
Load the dataset

Build probability dictionaries for each unique value

Classify unknown examples based on calculated probabilities

- Extensions and Improvements
Support for datasets with missing values
